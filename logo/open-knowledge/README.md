# MRCP Gafar — approved Open knowledge logo

Approved by Mohamed Gafar on 2 October 2026 for future project use. This is the **right-hand logo with rounded inner G corners** from the final comparison in `brand/`: the wider open-book G, mint page fold and rounded crossbar. This folder is the committed, self-contained artwork package; the exploratory brand files are not required to use it.

## Artwork

| File | Use |
| --- | --- |
| `icon.svg` | Master flat symbol; white book and mint fold on blue |
| `lockup.svg` | Symbol and MRCP Gafar name, without a tagline; compact headers |
| `lockup-dark.svg` | Name lettering adapted for dark backgrounds |
| `lockup-tagline.svg` | Full lockup with Internal Medicine Education tagline |

Each SVG has a matching PNG preview. The symbol also has `icon-16.png`, `icon-32.png`, `icon-64.png`, `icon-180.png`, `icon-512.png` and `icon-1024.png` exports. Use SVG wherever supported; the logo and lettering are outlined paths with no external fonts or image dependencies.

## Appearance

- Tile: #1F4E8C; book: #FFFFFF; fold: #5EE0C4.
- Name: heavier MRCP in #12304F, lighter Gafar in #1F7FBF.
- Dark lockup: MRCP in #FFFFFF and Gafar in #6FB3E6.
- The name uses the project's custom outlined lettering. The tagline is also outlined, smaller and muted.
- Keep the proportions and the rounded G crossbar. Do not stretch, rotate or crop the book; the avatar's blue background can be cropped to a circle.
- Use the lockup without a tagline in compact headers; reserve the tagline for larger placements.

## Integration status

Approved artwork is stored for later integration. The active site continues to load its existing symbol from `engine/logo.svg`. When adopting this logo, update that asset, the relevant exports and the Brand / Logo sizes rules in `DESIGN.md` together, then rebuild and run the page checks. Do not copy an experimental comparison board into a production header.

## Verification

Inspected the rounded symbol, small exports and monochrome treatment. The SVGs parse correctly, share the same page geometry and require no external assets. The full-bleed avatar fits its circular crop. This is an artwork-only commit; no curriculum or engine behaviour changes.
