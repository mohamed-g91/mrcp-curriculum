# Open knowledge — wider G

This revision addresses the narrow, tall G in the first vector redraw. The right page widens from 67 to 87 units, with a more rounded inner space and a shorter inward crossbar. Its nominal inner width grows from 33 to 51 units. The left page and spine move slightly left to give the G that room; the tile remains 210 × 210, and the symbol's height, colours and name lettering are unchanged.

`comparison.png` and `comparison.svg` show the first and wider marks at equal sizes beside the same wordmark, plus native 32 and 64 px versions. `preview.png` shows the new mark with header, monochrome and circular-avatar treatments. The original assets remain in `../open-knowledge-vector/`.

The complete revised package contains `icon.svg`, `lockup.svg`, `lockup-dark.svg`, `lockup-tagline.svg`, monochrome and reversed symbols, `avatar.svg`, native PNG icon sizes and `youtube-800.png`. The logo SVGs use paths only; they have no image or font dependency.

Rebuild with `python brand/logo-proposals-2026-10-02/build-vector-wide.py`, then run `render-vector.cjs` with the Sharp package path and this folder as its asset-directory argument.

Visually inspected the comparison, large symbol, review board and native 16 px export. Parsed the SVGs and checked the rasterised avatar's actual glyph against a circular crop. This is an artwork refinement, not a change to the site's production logo.
