# Open knowledge — rounded inner G

The wider v2 G with rounded inner crossbar corners. The inner tip is a semicircle; its attachment uses smaller smooth turns. The crossbar retains its thickness, position and left extent. The wider book silhouette, mint fold, tile and name lettering are preserved.

`comparison.png` / `comparison.svg` show before and after at equal sizes. `icon.svg` is the revised master symbol. All lockups, monochrome treatments, avatar and native PNG sizes use the same revised path. The earlier artwork remains in the v1 and v2 directories.

Rebuild with `python brand/logo-proposals-2026-10-02/build-vector-rounded.py`, then rasterise with `render-vector.cjs`, passing the installed Sharp path and this directory. The builder reads the v2 paths and replaces the crossbar's sharp corners.

Inspected the comparison board, 180 and 32 px icons and monochrome treatment. Parsed the SVGs and verified that the main icon's left page and fold match v2. Production pages are not changed by this artwork package.
